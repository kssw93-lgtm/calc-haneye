# 계산기 재검토 (2026-09-09)

전체 공식 검증 완료를 의미하지 않는다. 테스트 통과와 법적 정확성 검증은 별개다.

## 이번 수정
- 주휴수당: 통상근로자 주40시간·5일 사업장 범위에서 주시간/40*8 적용. 실제 근무일수로 나누던 과다 산정 수정. 평균 월 환산계수는 사용자 입력에서 제거.
- 최저임금: 동일 주휴 산식, 주40시간 월209시간 적용, 기본 연도 2026. 기타 근로형태는 평균 환산.
- 적금: 가입 시 첫 납입하고 매월 납입하는 모델로 n부터 1개월 이자 적용. 기존 n-1부터 0개월 오류 수정. 예금/적금 입력 라벨 분리. 실제 상품별 일할계산은 미지원.
- 퇴직금: 입력을 마지막 근무일로 명시. 그 다음 날을 퇴직일로 하여 직전 3개월 달력 일수 자동 입력. 제외기간은 사용자 조정 필요.
- 취득세: 지방세법 제11조 산식의 소수 세율을 소수 넷째 자리까지 반올림. 일반 1주택 기본세만 지원.
- 급여: 실제 자동 보험료 계산과 맞지 않던 설명 수정.

## 남은 검토
- 간이세액표 전체 값과 자녀공제 최신 원문 재대조. 현재 구조 테스트만 통과한 것을 공식 전수검증으로 표현하지 않는다.
- 연차: 단시간근로자의 시간 비례 부여 및 정확히 1년 계약 종료 등 별도 모델 필요.
- 퇴직금: 1일 통상임금과 비교, 근로시간 요건/제외기간/1년 판정 보강 필요.
- 실업급여: 평균월급/30은 단순 추정. 단시간근로자의 하한 시간 산정 세칙 재검토 필요.
- 건강보험: 극단적인 고액/저액 보수의 상하한까지 전수 검증하지 않음.
- 대출/월세전환: 약정 금리와 전환율은 개인 계약값이므로 자동 고정 불가. 법정 상한과 협의 전환율을 혼동하지 않음.
- 중개보수: 서울표 확인. 경기·인천 현행 조례 재확인은 미완료.
