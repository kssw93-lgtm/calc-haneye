# 2026 간이세액표 데이터 검증 기록

- 검토일: 2026-09-03
- 원문: 소득세법 시행령 별표2, 2026.2.27 개정. 현재 법령 시행일 2026.7.1과 별표 개정일은 구분한다.
- 공식 PDF: https://www.law.go.kr/LSW/flDownload.do?flSeq=164357181
- PDF SHA256: AB78F130DD263B271EA5CF9C33DD9BF169641724F942F07FF2E261085444A48E
- 공식 국세청 설명: https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7862&mi=6583
- `scripts/extract-withholding.py`는 PDF의 표 격자 추출과 행 텍스트 추출을 각각 수행하고 완전 일치할 때만 JSON을 출력한다.
- 데이터는 770천원 이상 10,000천원 미만의 연속된 646행, 하한·상한 및 가족 1~11명의 13열이다. 하한 포함, 상한 제외. 모든 가족 열의 양 끝 금액을 회귀 테스트한다.
- 원문 첫 페이지의 자녀 공제액 20,830 / 45,830 / 추가 1명당 33,330을 적용하고 음수는 0으로 제한한다. 이후 원천징수 선택 비율과 지방소득세를 계산한다.
- 정기 월급만 지원. 1천만원 이상, 가족 12명 이상은 원문에 별도 산식이 있으나 현재 구현하지 않았으며 오류와 수동 입력 안내를 표시한다.
- 보험료 자동 산정은 포함하지 않는다. 본인 고지액을 직접 입력한다. 식대 외 비과세·학자금, 상여 지급월, 중도 입·퇴사, 외국인 특례 등은 수동 확인 대상이다.
- 새 데이터 반영 시 기존 테스트 외에 원문 버전·파일 해시·추출 결과·화면 결과를 다시 대조한다. 링크만 열었다고 최신 검토일을 갱신하지 않는다.
