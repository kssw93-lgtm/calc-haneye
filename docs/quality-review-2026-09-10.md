# 조건 선택·검색·광고 검토 2026-09-10

## 적용
- 취득세: 세대 기준 취득 후 주택 수 안내, 조건별 라디오 버튼, 조건 변경 시 이전 결과 숨김. 지원범위 밖에서 일반세율을 적용하지 않음.
- 주휴·예적금·중개보수·월세전환: 조건을 라디오 버튼으로 선택. 입력 변경 시 이전 결과 숨김.
- 연차·최저임금·실업급여: 입력 변경 시 결과 제거.
- 연차: 주15~40시간 미만에 일반 근로자 일수를 그대로 적용하던 문제를 계산 제한으로 완화. 시간 비례 계산 지원은 미완료.
- 개인정보 안내: 복지 검색어 외부 전송, 네이버 통계, Cloudflare, Google 광고 설정 경로 설명 추가.

## 완료로 간주하지 않을 항목
- 금융·세금의 모든 예외와 세액표 전체를 이번에 전수 대조하지 않음.
- 사전 선택된 기본값은 자격 판정이 아님. 이용자가 가족·주택·개근 등 실제 조건을 확인해야 함.
- API 복지 상세는 자체 사례·해석이 부족함. 해당 HTML에는 AdSense 스크립트가 없지만 사이트 전체 승인 보장을 의미하지 않음.
- 공통 레이아웃에는 AdSense 스크립트가 존재함. 수동 AdSlot 비활성화가 자동 광고 비활성화를 의미하지 않음.
- AdSense 계정 심사 상태, 자동광고 배치, 지역별 동의 플랫폼 설정은 콘솔 미확인.
- 검색 노출·AdSense 승인은 Google 결정이며 페이지 수나 테스트 통과만으로 보장되지 않음.
- 연차 시간 비례 산정, 퇴직금 통상임금 비교, 고액 급여 보험 상하한/간이세액표 재대조 후 추가 반영 필요.
